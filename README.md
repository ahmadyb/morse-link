# MorseLink

A small, fast Android app for Morse code: translate it, transmit it with the torch,
speaker, screen or vibration, and decode tones picked up by the microphone.

**Download the APK:** [`app/release/morse-link.apk`](app/release/morse-link.apk)
— signed, installable on any Android 8.0 (API 26)+ phone. Allow *install from unknown
sources* when your phone asks.

---

## What's inside

| Tab | What it does |
| --- | --- |
| **Codec** | Live two-way translation: type text and get Morse, or type `. - /` and get text. Copy, share, or send the result straight to the transmitter. |
| **Send** | Key any message out through up to four outputs at once — **torch**, **sound**, **screen flash** and **vibration**. Speed 5–40 WPM, tone 300–1200 Hz, optional repeat, one-tap **SOS**. |
| **Receive** | Point the mic at a Morse tone and watch it decode in real time. Tunable tone (400–1200 Hz) and sensitivity. |
| **Learn** | Full International Morse chart (tap any cell to hear it) and a listening quiz with a streak counter. |

Extras: shared text from any app can be sent straight into MorseLink, everything
( speed, tone, outputs, message, quiz best streak ) is remembered, and the screen
stays awake while you transmit.

## Building

```bash
./gradlew assembleRelease     # -> app/build/outputs/apk/release/app-release.apk
./gradlew installDebug        # build + install on a connected device
```

Requires JDK 17 and the Android SDK (compile/target SDK 35, min SDK 26).
GitHub Actions builds the signed APK on every push and refreshes
`app/release/morse-link.apk` — see [`.github/workflows/apk.yml`](.github/workflows/apk.yml).

The demo signing key lives in `keystore/morse-link.jks`
(alias `morselink`, password `morselink`) so clones stay installable. Replace it
with your own keystore before publishing anything.

## Notes

- **No third-party libraries.** Everything is built on the Android framework, which keeps
  the APK small and the build quick.
- Torch output uses the Camera2 torch API; the camera permission is only requested when
  you actually enable the torch or the quiz playback.
- Microphone decoding is a Goertzel tone detector plus a timing state machine. It likes
  clear, steady tones in a quiet room; use the **Tone** and **Sensitivity** sliders to
  match the source.
- Permissions used: `CAMERA` (torch), `RECORD_AUDIO` (receive), `VIBRATE`, `FLASHLIGHT`.

## Layout

```

├── MainActivity.java   # the four tabs and all wiring
├── MorseCodec.java     # International Morse tables, encode/decode/timing
├── Transmitter.java    # torch / sound / screen / vibration keying
├── Receiver.java       # microphone tone detection and decoding
└── Prefs.java          # SharedPreferences wrapper
```
